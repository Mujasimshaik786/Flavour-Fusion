🍳 **Flavour Fusion – AI-Driven Recipe Blogging Platform**

Flavour Fusion is an AI-powered recipe blogging web application that generates unique, detailed, and customized recipe blogs using Google’s Gemini Generative AI.

The platform is designed for food bloggers, home cooks, and content creators who want high-quality recipe content with minimal effort.
This project is developed as part of the SmartInternz Virtual Internship Program (Group Project).

**🚀 Project Overview**

Flavour Fusion allows users to:

-> Enter a recipe topic

-> Select a preferred cuisine

-> Choose a desired word count

-> and instantly generate a well-structured, engaging recipe blog.

-> While the AI processes the content, the application also entertains users with light-hearted programmer jokes, making the experience       interactive and enjoyable.

**✨ Key Features**

🤖 AI-Powered Content Generation using Google Gemini

📝 Customized Recipe Blogs based on topic and word count

🍽️ Multiple Cuisine Options (8 cuisine types + Any)

🎯 Flexible Word Count (100–5000 words)

🎨 User-Friendly & Responsive Interface

📥 Download Generated Recipes as text files

💾 Recipe History Tracking

😄 Fun Programmer Jokes during content generation

**🧑‍💻 Technology Stack**

Frontend & UI: Streamlit

AI Model: Google Gemini (Generative AI)

Backend Logic: Python

Environment Management: python-dotenv

**⚙️ Installation & Setup**

1️⃣ Prerequisites

Ensure the following are installed on your system:

Python 3.9 or above

pip (Python package manager)

2️⃣ Clone the Repository

git clone  https://github.com/Mujasimshaik786/Flavour-Fusion.git

cd Flavour-Fusion

3️⃣ Create Virtual Environment & Install Dependencies
python -m venv .venv

.venv\Scripts\activate     # For Windows

pip install -r requirements.txt

4️⃣ API Key Configuration

Create a .env file in the root directory and add your Google Gemini API key:

GOOGLE_GEMINI_API_KEY=your-api-key-here

🔑 You can obtain the API key from Google AI Studio.

5️⃣ Run the Application

streamlit run app.py

Open your browser and visit:

http://localhost:8501

**📖 How to Use the Application**

-> Enter a recipe topic (e.g., “Vegan Chocolate Cake”)

-> Select a cuisine type or choose Any

-> Set the desired word count

-> Click Generate Recipe

-> View, download, or save the generated recipe blog
